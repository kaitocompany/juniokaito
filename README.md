# @juniokaito

Página independente pronta para GitHub Pages. Publique os arquivos desta pasta na raiz de um repositório público. Em **Settings → Pages**, escolha **Deploy from a branch**, a branch `main` e a pasta `/ (root)`.

A página abre em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`. O link de “Iniciar conversa grátis” aponta para `https://www.instagram.com/juniokaito/`; altere esse endereço em `script.js` caso queira outro canal de contato.
