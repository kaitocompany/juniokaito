# @juniokaito

Site independente em HTML, CSS e JavaScript. Os arquivos da página ficam na raiz do repositório: `index.html`, `style.css`, `extra.css`, `script.js` e `favicon.svg`. Não precisa instalar dependências nem executar uma compilação.

O GitHub Pages usa a branch `main` e a pasta `/ (root)`. O domínio personalizado é `juniokaito.com`, configurado em **Settings → Pages**. Para o domínio abrir, os registros A de `@` no provedor de DNS devem apontar para os quatro endereços oficiais do GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.

A página funciona de forma independente. As redes sociais são links externos; o botão de conversa da Loja aponta para `https://app.kaitocompany.com/`. Para trocar esse destino, edite o link em `script.js`.
